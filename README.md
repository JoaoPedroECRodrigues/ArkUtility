# 🦖 ArkUtil Bot

Um bot interativo e inteligente para comunidades de **ARK: Survival Evolved / Ascended** no Discord. O ArkUtil foi projetado para ser o braço direito da administração, fornecendo aos jogadores acesso rápido e fácil a lojas, comandos, regras e multiplicadores diretamente pelo Discord, utilizando **Slash Commands** e **Menus Interativos (Dropdowns)**.

---

## ✨ Funcionalidades

- **Slash Commands Nativos:** Comandos modernos (`/menu`, `/sobre`) totalmente integrados à interface do Discord.
- **Menus Suspensos Interativos:** Navegação limpa e intuitiva sem poluir o chat.
- **Filtro por Servidor (Guild ID):** O bot identifica em qual servidor está sendo usado. O servidor de "Testes/Admin" tem acesso global a todos os painéis, enquanto os servidores de clientes visualizam apenas os dados da própria comunidade.
- **Lojas Segmentadas:** Organização de itens por categorias (Dinos, Recursos, Tributos, Equipamentos e VIP).
